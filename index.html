深海里的小鲸,人间的小漫画

鲸漫天堂收录 DeepSeek 鲸鱼娘同人小漫画。全部漫画由社区通过 GitHub 投稿, 点「上传漫画」看看怎么把你的鲸放进来。

最新收录
投稿方式 两种,任选

① Pull Request —— Fork 本仓库,在 comics/<你的漫画id>/ 里放进页面图片,并在根目录 comics.json 登记一条,提 PR 即可。格式与限制见 仓库 README。

② Issue 附件 —— 不想动 Git?打开仓库的 新 Issue, 标题写漫画名,图片拖进正文,维护者会替你上架。
